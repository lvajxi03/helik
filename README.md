# HeliK!

Side-scroller copter game, just like `Flappy Bird`, but with some more features (or bugs?)

![](C:\proj\helik\pysrc\helik\resources\images\001-about.png)

## Game

The goal of this game is very obvious: you have to survive. 

## Requirements

`HeliK` package requires `pygame` to run. All dependencies are installed together with `HeliK` package.

## How to install

`Helik` can be found in `pypi` repository, so all you should to is type the following:

`$ pip install helik`

in your terminal to install this game.

## How to uninstall

To uninstall, type the following:

`$ pip uninstall helik`

in your terminal
